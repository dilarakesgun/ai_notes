compare&pull request => 2 branch arasında nelerin değiştiğini gösterir, çakışma yoksa merge edebiliriz der


git branch -r => remote branchleri gösterir


git fetch=> remote'taki tüm yeni commitleri , branchleri , commit geçmişini local bilgisayarınıza indiren ancak mevcut kodunuza veya çalıştığınız branche müdahele etmez, güvenlidir.


git checkout origin  => remote sunucunun ana kopyası origine bağlar ve local bir branchte olmadığınız için kod üzerinde yapacağınız değişikliklerin kaydedilmeyeceği detached HEAD durumuna sokan inceleme komutudur.


git pull=> git fetch + git merge
değişiklikleri al direkt benim projeme yerleştir


git clone link => github'taki mevcut bir repository birebir kopyasını üzerinde çalışabileceğim şekilde local bilgisayarıma indirir.


fork 'lamak => başka birine veya kuruma ait bir repository'nin tamamını, orijinal projeyi etkilemeden üzerinde özgürce değişiklik yapabilmemiz için kendi github profilime kopyalar. yaptığım değişikliklerden sonra pull request yapabilirim (contribution)
